# robotics-learning

机器人 / 具身智能 学习门户 —— 从客户端工程出发，面向未来落地方向，扎实吃透机器人工程的工作流与储备知识。

## 在线浏览

**➡️ https://fengur.github.io/robotics-learning/**

## 结构

- `index.html` —— 可视化门户（演进时间线 + 模块路线 + 里程碑看板，进度存本地浏览器）
- `read.html` —— markdown 在线阅读器（让 md 在 Pages 上渲染成漂亮页面）
- `00-领域地图.md` —— 历史演进、范式、分层架构、sim2real、定位判断
- `01-学习路线.md` —— M0-M4 模块清单 + 里程碑
- `notes/` —— 每模块边做边记的实战笔记
- `demos/` —— 里程碑产出的可跑代码/工程
- `复盘.md` —— 每个里程碑复盘

本地看：直接用编辑器读 md，或双击 `index.html`（门户本身可离线用；md 阅读器因浏览器 `file://` 限制需在线访问）。
