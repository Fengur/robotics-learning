## 二、环境搭建（动手）—— ✅ 里程碑1 已点亮 2026-08-05

**选型**：**RoboStack**（conda 装 ROS2，原生跑 Mac，免 Docker/免虚拟机/免管理员权限）。
> 不用 Docker：公司禁 Docker，且 conda 装到用户目录足够。不用虚拟机：Apple Silicon 原生跑最快。

### 环境信息
- **ROS2 版本**：Humble（LTS，资料最多、RoboStack 支持最成熟）
- **conda 发行版**：miniforge（arm64 原生），装在 `~/miniforge3`
- **conda 环境名**：`ros_humble`（Python 3.11）
- **只装了 `ros-humble-ros-base`**（核心，含 `ros2` CLI + tf2 + rosbag2）+ demo 节点。**没装 desktop**（rviz/gazebo 等 GUI 上百包、solve 巨慢，里程碑1用不到，留到 M2 仿真再装）。

### 每次用之前（激活环境）
```bash
source ~/miniforge3/etc/profile.d/conda.sh
conda activate ros_humble
# 之后 ros2 命令就能用了。ROS_DISTRO=humble
```

### 验证命令（里程碑1 验收）
```bash
ros2 --version              # 确认 CLI 可用
ros2 pkg list | grep demo   # demo_nodes_cpp / demo_nodes_py

# 两个终端分别跑,看它们对上话:
ros2 run demo_nodes_cpp talker      # 发: Publishing: 'Hello World: N'
ros2 run demo_nodes_py listener     # 收: I heard: [Hello World: N]
```
**跑通标志**：listener 收到的序号和 talker 发的一一对应 = 两个进程通过 ROS2 中间件（第2层）完成了发布/订阅通信。**这就是"抓杯子"链路里 `相机→中间件→感知规划` 那一段的最小活体。**

## 三、踩坑记录（国内网络，血泪）

1. **miniforge 下载慢**：GitHub 直连 ~50KB/s。换清华镜像 30 秒下完：
   `https://mirrors.tuna.tsinghua.edu.cn/github-release/conda-forge/miniforge/LatestRelease/Miniforge3-MacOSX-arm64.sh`
2. **国内镜像没有 robostack channel**：tuna/bfsu/ustc/nju/sjtug 全部 404 或重定向回清华（清华也没有）。**robostack-staging 只能走官方源 `https://conda.anaconda.org`**。`~/.condarc` 里 conda-forge 指清华镜像（依赖多、要快）、robostack 指官方源，`channel_priority: strict`。
3. **robostack 官方源国内直连 SSL 超时**：间歇性连不上。**必须挂 VPN**（全局/TUN 模式即可，无需配代理端口；开任意境外节点后 `conda.anaconda.org` 秒通）。**VPN 只下载时需要，装完跑 ROS2 纯本地不用 VPN**。
4. **mamba solve ROS2 大依赖图 >5min**，会被终端 5 分钟超时反复打断。且内联 `nohup mamba install...` 不生效（环境没激活空跑就退），**必须写成 .sh 脚本文件**（脚本内 source+activate+install）再 `nohup bash x.sh &`。macOS 无 `setsid`/`timeout` 命令。
